# Restricted raw data

Raw CoinGecko API exports are not included in the public repository. Obtain them directly from CoinGecko under an appropriate licence, preserve the expected source directory structure, and either:

- set `COINGECKO_DATA_ROOT=/absolute/path/to/coingecko` for Section 4.5; or
- set `FRM_COINGECKO_ROOT=/absolute/path/to/coingecko` for Section 6.1.

The bundled frozen section inputs are sufficient to reproduce the reported tables and figures without these raw exports.
