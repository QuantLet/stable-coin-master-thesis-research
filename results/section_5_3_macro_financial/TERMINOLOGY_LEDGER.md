# Terminology ledger

| Canonical term | Definition / decision |
|---|---|
| Depegging Pressure Index (DPI) | Daily mean of the 11 selected Quantile-Lasso penalties; not a depeg probability. |
| Quantile Lasso | Capitalized method name; τ=0.05 in the primary analysis. |
| active set | Predictors with absolute coefficient above (10^{-10}). |
| selection frequency | Fraction of eligible target-window equations in which a predictor is active. |
| sign balance | Positive-selection frequency minus negative-selection frequency. |
| standardized coefficient-weight share | Absolute robust-scaled coefficient divided by the relevant coefficient-mass denominator; descriptive, not causal or incremental. |
| Newey-West HAC(90) | Bartlett-kernel heteroskedasticity- and autocorrelation-consistent covariance with lag 90. |
| CVIX | Deutsche Bank Currency Volatility Index. |
| DXY | U.S. Dollar Index. |
| one-year Treasury yield | Bloomberg series BV010082; use this readable label in the main text. |
| S&P 500 | Use this form in prose; source-data label is SPX. |
| reference-adjusted signed deviation | Stablecoin price divided by its own reference-asset price minus one. |
| macro-financial association | Preferred interpretation; do not substitute causal “transmission” without identification. |
