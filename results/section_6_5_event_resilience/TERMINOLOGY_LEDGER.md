# Terminology ledger

| Term | Canonical definition |
|---|---|
| EW | Equal-weight portfolio |
| GMV | Global minimum-variance portfolio based on trailing reference-adjusted return covariance |
| LTEC | Linear tail-event-comovement portfolio based on lagged coin-specific Quantile-Lasso penalties |
| QTEC | Quadratic tail-event-comovement portfolio combining lagged lambda exposure and trailing lambda covariance |
| DPI | FRM-based depegging pressure index |
| 5% ES | Mean portfolio loss conditional on returns at or below the empirical 5% quantile |
| Event window | Calendar days 0–30 after a frozen event date |
| Acute window | Calendar days 0–7 after a frozen event date |
| Event-stratified bootstrap | Moving-block resampling performed separately inside each event window before pooling the sampled returns |
| Maximum drawdown | Largest peak-to-trough loss within an event window, measured from an initial wealth of one |
