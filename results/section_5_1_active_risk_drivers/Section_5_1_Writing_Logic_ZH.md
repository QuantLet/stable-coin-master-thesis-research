# 5.1 写作逻辑

这一节需要实证，否则只能重复 Quantile Lasso 的方法说明。它应回答一个窄而清楚的问题：构成 DPI 的下尾回归是否始终依赖同一组变量。

正文按四步展开：

1. 先区分“压力强度”和“驱动因素构成”。DPI 概括惩罚强度；active set 说明哪些变量被保留。
2. 报告总体稀疏度，并按各组可进入模型的机会数标准化。每个方程有 10 个稳定币候选变量、5 个宏观变量，不能直接用所选变量的原始占比判断哪一组更重要。
3. 比较五个 DPI 状态，说明 active set 是否随压力水平改变。该比较只能作为描述性证据，因为 DPI 和 active set 来自同一次惩罚估计。
4. 用月度热图呈现变量身份的时间变化，再明确选择频率不等于系数大小、因果影响或风险传染，并自然引向 5.2 和 5.3。

主文保留一张表和一幅图即可。Table 5.1 报告各 DPI 状态下的 active-set 规模及标准化组别纳入率；Figure 5.1 报告每个变量的月度选择频率。逐变量完整结果、年度结果和目标币结果放入附录。

不建议在本节增加普通日频显著性检验或预测回归。90 日滚动窗口高度重叠，而且状态变量与 active set 同源；常规 t 检验会夸大有效样本量，预测回归也偏离本节的构成问题。
