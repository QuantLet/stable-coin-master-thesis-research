# Section 5.2 terminology ledger

| Canonical term | First-use definition | Variants found | Decision |
|---|---|---|---|
| stablecoin | A token intended to track a designated reference asset | stable coin; Stable Coin | Use one word throughout prose and headings. |
| Quantile-Lasso | L1-penalised quantile regression | Quantile Lasso; quantile lasso | Use the hyphenated form consistently. |
| Depegging Pressure Index (DPI) | Mean selected target-specific penalty in the primary lower-tail system | Stable DPI; Stablecoin DPI | Define once, then use DPI. |
| reference-adjusted signed peg deviation | Token price divided by its own reference-asset value minus one | peg deviation; signed deviation | Use the full term at first use; peg deviation thereafter. |
| active set | Predictors with absolute selected coefficient above 1e-10 | selected variables; active drivers | Use active set for the formal object. |
| downside-aligned conditional link | Positive selected coefficient in a lower-tail target equation | positive link; tail-risk spillover | Use the canonical term; do not call it contagion. |
| inverse conditional link | Negative selected coefficient in a lower-tail target equation | negative link | Use the canonical term at first use. |
| source stablecoin | Stablecoin predictor in a target equation | sender; risk output centre | Use source only as equation orientation, not causal timing. |
| target stablecoin | Response stablecoin in the conditional quantile equation | receiver; risk reception centre | Use target only as equation orientation. |
| conditional association | Model relationship holding the remaining predictors fixed | transmission; spillover; effect | Reserve causal language unless a separate identification design is introduced. |
