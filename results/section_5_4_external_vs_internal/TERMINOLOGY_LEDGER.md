# Terminology ledger

| Term | Definition used in Section 5.4 |
|---|---|
| Conditional GACV | Minimum finite GACV selected within a 90-day Quantile-Lasso window |
| Conditional skill | Percentage reduction in selected GACV relative to the intercept-only benchmark |
| Out-of-sample check loss | 5% quantile loss on a held-out observation using parameters and scaling estimated through the preceding day; predictor timing is reported separately |
| Same-day conditional | Other stablecoin deviations are observed on the target date; macro changes remain lagged one day |
| All predictors lagged | Both stablecoin and macro-financial predictors are dated no later than \(t-1\) |
| Incremental coin information | Macro-only loss minus joint-model loss |
| Incremental macro information | Coin-only loss minus joint-model loss |
| Internal spillover | Conditional coin-to-coin lower-tail information; not a claim of fixed causal direction |
